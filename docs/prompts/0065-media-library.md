# Media library

## Prompt
And in Oi, we should have a media library that acts as a catch-all for all images, with sorting and filtering as appropriate, and somehow automatically connected with the website front end and the images that are loaded for classes, teachers, etc. in the future, and including anything that's active or inactively published, marked properly in the media library and linked properly. Also, I'm going to give you four images, which you can set properly for light and dark mode, for instance the orange and blue, or maybe we can come up with a nice effect to very slowly transition between them rather than using in light or dark mode. That could be very nice. I'll give you those images now.

## Response
The asset library indexes packaged media and connects class and teacher media from the same provider used by the frontend. Search, source/type/orientation/status filters, sorting, thumbnails, placement links and non-destructive responsive variants are available in M-02d. The separate placement editor remains accessible. Four additional equipment images were approved for public use. Metadata-stripped responsive variants are preserved separately and used in a slow, pausable, reduced-motion-aware dissolve in the opt-in About gallery.
