The HOY script wordmark, traced from the brand manual (Manual de marca 2026).

- `hoy-wordmark.svg` — vector, single ink `#35597D` (brand-deepBlue). Use on cream, paper and plaster grounds.
- `hoy-blue.png` — deep blue on transparent.
- `hoy-cream.png` — cream `#F1E7D2` on transparent. Use on the deep-blue menu and heroes.
- `hoy-yellow.png` — sun yellow `#F7F3B2` on transparent. Use on deep blue for celebratory moments.

Clear space equals the H height of the full lockup (⅓ of the script height). Minimum 120 px wide on screen, 30 mm in print. Never recolour outside these three inks, stretch, outline or add effects.
