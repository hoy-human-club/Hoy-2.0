Photographed studio materials used behind the interface (Pulso Materia, 0170).

- `texture-limestone.webp` — sun-washed limestone plaster. The page ground of the staff workspace, the hub and the member app, under an 84% `color-bg` veil (82% on the hub), fixed to the viewport.
- `texture-blue.webp` — blue plaster. Multiplied into `brand-deepBlue` for the side menu and the hub hero.
- `texture-sunlight.webp` — leaf shadows from the window. 18% opacity, multiply, masked to the top-right corner of the page.

Dark mode never shows these photographs: it uses the procedural stone and grain instead. Materials always sit behind content, never on top of text.
