# S-08 · Reception · voucher verification

Route: `/#/staff/vouchers`.

Reception, coordination and admins look up a short code or full same-origin promotion link. Verify the actual test holder and choose their individual voucher. Existing bookings can be confirmed; walk-ups can be booked only when balance, participant limits and capacity allow. Booking deducts the benefit. Reception confirmation and attendance are separate actions and never charge it again. This fictional local demo is not a real check-in system.

Production boundaries: [promotion backend readiness](../promotion-backend-readiness.md).
