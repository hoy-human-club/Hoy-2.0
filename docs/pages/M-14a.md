# M-14a · Class pay / Pago por clase

Route: `/#/admin/class-pay`. Admin, super-admin and finance only. Select a recurring template to configure future pay rules. The same panel appears on administrator template and dated-session editors.

New templates receive a COP 100,000 flat-class default. Existing templates without a new rule remain unconfigured here, preserving old payroll settings. Effective-dated append-only rules can specify a flat amount or an explicitly configured participant formula and count basis. There is no guessed attendance formula and no live payment. Existing payroll snapshots remain unchanged.

The private rules table is separate from public catalogue records. The mock UI is not a production security boundary; authenticated backend access enforcement remains required. Never put private teacher agreements in repository fixtures.


QA screenshots are retained locally outside the repository and public deployment. The public hub map intentionally has no captures for this protected screen.
