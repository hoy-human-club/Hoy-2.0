# C-08b — Cancel or reschedule sheet

**Route** `/#/app/booking/:id/change` · **Roles** — · **Surface** customer · **Spec** `spec.code === 'C-08b'` (see `/#/dev/specs`)

## Purpose
One button on the booked class opens one sheet, because a student who cannot make a class is taking a single decision with two outcomes. Moving is offered first — it keeps the credit and keeps the habit.

## Logic and integrations
- Move = replacement + original cancellation in one isolated mock transaction, with the same spent entitlement and no ledger debit.
- Cancel returns the credit immediately when outside the window; inside it the credit is spent and the sheet says so before confirming.
- Rescheduling uses the source-defined inclusive 12-hour deadline (RS-09); cancellation still uses the separate draft setting. Jas cancellation questions remain unresolved.
- The date selector offers scheduled future classes with room within the original purchase expiry/freeze. Ambiguous package allocation stops with reception help. Legacy non-package bookings without purchased terms retain same-day moves only.
- Reception booking/attendance actions are separate S-02 flows; this customer reschedule receipt does not assert staff reschedule acceptance.
- Backend integration pending: authenticated atomic reschedule, entitlement reconciliation and authoritative capacity; no actual Realtime service is connected.

## States
- Outside window (this sheet)
- Inside window: destructive confirm naming the forfeited credit
- No eligible replacement on selected date; choose another date
- Persistence failure: original remains active and retry is offered
- Missing original purchased terms: help notice; no guessed future validity
- Past class: sheet cannot open

## Real vs mock
- Rendered frontend: reads through `useData()` / `useTable`; the mock atomic command stages every changed record. A provider without `atomic` stops explicitly; backend replacement needs its own authorized server command.
- Mock / pending: Supabase Realtime are simulated or deferred; data is the browser-local `MockProvider` seed.
- Note: Opens as a bottom Drawer over C-08 at /app/booking/:id/change.
